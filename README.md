# Ayurdaay Chikitsalay — Official Website

This repository is reserved for the Ayurdaay Chikitsalay public website.

## Publishing the prepared website

Upload the **contents** of the final website package into the repository root (not the ZIP itself). Required files: `index.html`, `diya-original.png`, `original-full-logo.jpg`, `doctor-profile.png`, and `gpay-qr-original.jpg`.

After committing files, open **Settings → Pages → Build and deployment → Deploy from a branch**, select `main` and `/ (root)`, then Save.

Expected public URL after GitHub Pages deployment: https://sourabhdargad77-wq.github.io/ayurdaay-website/

Note: Orders and payment screenshots are handled through WhatsApp; browser-local admin edits do not publish automatically to GitHub Pages. Do not treat QR payments as verified without manual confirmation.
